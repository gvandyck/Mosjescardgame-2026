Board tiles
What a card looks like on the table (direction A). The full card text lives in the hover / tap panel.
  • Same look as the hand card: black frame, 2 px type line (none on Mosjes), Sora / DM Sans, tint labels.
  • Mosje tile: name · LVL n (top-right, tint) · traits line (for Quest rolls) · remember-line (ability, max 2 lines) · Power (+ Place buff chip) · MP · 3 px MP bar along the bottom (white fill = MP %, red = damage preview).
  • Level: LVL n comes from the level marker; Power and traits from that level’s strip row. Ultimate on top: the tile shows the Ultimate (its art, Power, traits, ability) with a foil wash; LVL and MP stay.
  • Piecie / Snelle tile: cost · name · effect line · type label in tint. Place: name · effect line · PLACE. Quest: NEED · name · roll line · WIN / LOSE · “Rolls …”. No fail pips (a Quest leaves after one attempt).
  • Tile unit: u = width ÷ 240. Art inset 6u, radius 13u, type line inset 2.2u, header 10u from the top / 12u from the sides, name 15u, numbers 21u, labels 6u, footer 10u from the bottom, remember-line 9.5u DM Sans.
  • Phone: Mosjes 142 × 104, others 118 × 86. The remember-line and traits drop; numbers and names stay (names ≥ 11 px).
  • Remember-line text: new field per card (e.g. tileText), drafted by Claude Code, approved by Gandalf. Never auto-shortened rules text.
