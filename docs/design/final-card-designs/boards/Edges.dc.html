Text rules & edge cases
The longest real cards in src/data, rendered with the rules below. All fit in a browser render with Sora and DM Sans.
  • Auto-fit: card text starts at 18 px (items) / 16 px (Mosjes) and steps down until it fits; minimum 12.5 / 13 px. The bottom fade grows with the text.
  • Keywords (bold white, always the same words): Needs: a condition that must be true · Pay: something you give up first · Roll: the dice · Win: extra reward · Good for: / Bad for: on Places · Stays … (the card’s own duration sentence) · ability names (Chaos Roll:). Nothing else is bold.
  • Order: Needs → Pay → Roll → card text → Win. Places: Good for / Bad for first. Mosjes: ability (+ “From LV3:” line), then the level strip.
  • Names: one line, Sora 800, 40 px down to ~22 px to fit. Epithet one line, ≤ 20 px.
  • Text is never reworded, only split at sentence breaks. Bold = ability name or keyword.
  • No art yet: the art window shows a gradient in the type colour (placeholder, not a style).
  • Contrast: text stays ≥ 4.5 : 1 on the fade; raise the fade over bright art, never add a box.
