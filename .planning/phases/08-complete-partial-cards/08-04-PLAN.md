Inside the `loseMP` function, after the existing place effect checks (momentum stabilizer cap, zo_is_natuur cap) and before `mosje.mp -= lossAmount`, add the following snelle flag interception block.

The flags live on `gameState._snelleFlags` (the deep-cloned `state._snelleFlags` at that point).

```javascript
// ── Snelle Piecie interception flags ──────────────────────────────────────
const snelleFlags = state._snelleFlags || {};

// Counter Strikka: negate next Piecie-sourced MP loss for this player.
// No dedicated 'PIECIE' source tag exists; piecies always invoke loseMP with source='DRAIN'.
// Approximation: intercept source === 'DRAIN' only (excludes ATTACK, QUEST, DIRECT).
if (snelleFlags.negateNextPiecie?.[playerId] && source === 'DRAIN') {
    console.log('[MP] Counter Strikka: Piecie/DRAIN damage negated for', playerId);
    delete state._snelleFlags.negateNextPiecie[playerId];
    return state; // damage fully negated — return without applying
}

// Perfect Dodge: negate next ATTACK source + gain 15 MP for the defender
if (snelleFlags.negateNextAttack?.[playerId] && source === 'ATTACK') {
    console.log('[MP] Perfect Dodge: ATTACK negated for', playerId, '— +15 MP refund');
    mosje.mp += 15;
    delete state._snelleFlags.negateNextAttack[playerId];
    return state; // damage negated, bonus applied
}

// Drain Reversal: reflect incoming drain to opponent
if (snelleFlags.drainReversal?.[playerId] && source === 'DRAIN') {
    const oppId = Object.keys(state.players).find(id => id !== playerId);
    if (oppId) {
        const opp = state.players[oppId];
        const osi = opp.activeSlots.findIndex(s => s && !s.isDefeated);
        if (osi >= 0) {
            opp.activeSlots[osi].mp -= lossAmount; // direct mutation (bypass stack to avoid recursion)
            opp.activeSlots[osi].mp = Math.max(0, opp.activeSlots[osi].mp);
            console.log('[MP] Drain Reversal: reflected', lossAmount, 'drain to opponent');
        }
    }
    delete state._snelleFlags.drainReversal[playerId];
    return state; // damage reversed, not applied to self
}

// Dierenasiel passive: PET protection reduces any incoming loss by 25%
if (state.dierenasielActive) {
    lossAmount = Math.floor(lossAmount * 0.75);
    console.log('[MP] Dierenasiel: PET protection — reduced loss to', lossAmount);
}
// ── End snelle interception ───────────────────────────────────────────────
```

Insert this block immediately after the `place_zo_is_natuur` resilient check (line ~93 in the current file) and before `mosje.mp -= lossAmount`.

IMPORTANT: The snelle flags block must come AFTER the cloneState (`const state = deepCloneState(gameState)`), so it operates on the mutable clone. The `mosje` variable is already pointing into the cloned state at that point.
