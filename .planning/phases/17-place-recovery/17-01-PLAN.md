<objective>
Unify the card graveyard model so every card a player owns ends up in that player's personal `player.discard` pile, regardless of card type.

**Two engine changes:**

1. **Place ownership routing** — When a Place is replaced (`setActivePlace`) or destroyed (`destroyActivePlace`), push the card to the Place owner's (`activePlacePlayedBy`) personal `player.discard` as `{ cardId, type: 'PLACE' }`. Remove `sharedPlaceDiscard` entirely.

2. **Mosje dual-write** — When a Mosje is defeated (`markMosjeDefeated`), continue pushing the full slot object to `player.welloe` (required by Mosje Reborn and other revival mechanics), AND ALSO push `{ cardId: mosje.cardId, type: 'MOSJE', level: mosje.level, mp: mosje.mp }` to `player.discard`. This means `player.discard` becomes the unified graveyard visible to card effects, while `player.welloe` remains the authoritative store for full revival data.

**Edge case — null activePlacePlayedBy:** If a Place is replaced/destroyed but `activePlacePlayedBy` is null (e.g. engine set place without a player context), fall back to `state.activePlayerId` so the card always lands somewhere sensible.

**Tesla exception unchanged:** The victoryChecker.js Tesla hook already pushes to the player's own discard directly — no change needed there.
</objective>
