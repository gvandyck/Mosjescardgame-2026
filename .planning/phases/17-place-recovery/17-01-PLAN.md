<objective>
Implement Place recovery mechanics so players can get their Places back after an opponent replaces or destroys them. Three changes:

1. **Slecht Gezet** (rework) — ownership-aware: if the active Place is YOURS, return it to your hand. If it's the OPPONENT'S, destroy it as before. No modal needed — ownership is auto-detected via `state.activePlacePlayedBy`.

2. **Huisbaas** (rework) — replace the DEFERRED deck-search with a working "return top Place from sharedPlaceDiscard to hand" mechanic. Remove the SUBSTANCE condition entirely. Simple, immediate, useful.

3. **Chillingsvoorbij! (NEW snelle)** — "The chilling is done." Instant response card: return the top Place card from `sharedPlaceDiscard` to your hand. Same engine effect as Huisbaas but instant-speed, letting you react the moment an opponent replaces your Place mid-turn.

**Why sharedPlaceDiscard works for recovery:** When any Place is replaced or destroyed, `gameState.js:destroyActivePlace()` and `setActivePlace()` both push `{ cardId, type: 'PLACE' }` to `state.sharedPlaceDiscard` (unshift, so index 0 = most recently lost). This pile already exists — no engine changes needed.

**Physical Force deck update:** Add `snelle_chillingsvoorbij` to the Physical Force snelle deck, replacing `snelle_lucky_coin` (two copies currently → reduce to one, add the new recovery snelle).
</objective>

```js
// NEW effect_slecht_gezet(gameState) — playerId NOT needed, use state.activePlayerId
export function effect_slecht_gezet(gameState) {
  if (!gameState.activePlace) {
    console.log('[ABILITY] Slecht Gezet: no active Place');
    return gameState;
  }
  const state = cloneState(gameState);
  const activePlayer = state.activePlayerId;
  const placeOwner = state.activePlacePlayedBy;

  if (placeOwner === activePlayer) {
    // YOUR own Place → return to hand
    const player = state.players[activePlayer];
    if (player) player.hand.push({ cardId: state.activePlace, type: 'PLACE' });
    state.activePlace = null;
    state.activePlacePlayedBy = null;
    state.activePlaceTurnsActive = 0;
    console.log('[ABILITY] Slecht Gezet: returned own Place to hand');
  } else {
    // Opponent's Place → destroy it
    const destroyed = state.activePlace;
    if (!Array.isArray(state.sharedPlaceDiscard)) state.sharedPlaceDiscard = [];
    state.sharedPlaceDiscard.unshift({ cardId: destroyed, type: 'PLACE' });
    state.activePlace = null;
    state.activePlacePlayedBy = null;
    state.activePlaceTurnsActive = 0;
    triggerPlaceDestroyedEffects(state, activePlayer);
    console.log('[ABILITY] Slecht Gezet: opponent Place destroyed');
  }
  return state;
}
```
