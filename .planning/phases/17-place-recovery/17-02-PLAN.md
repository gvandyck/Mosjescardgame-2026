Implement the three Place recovery card mechanics, reading from the unified per-player discard established in Plan 01.

1. **Slecht Gezet** (rework) — Ownership-aware, no modal needed:
   - Active Place is YOURS (`activePlacePlayedBy === activePlayerId`) → return directly to your hand. Does NOT go to discard first.
   - Active Place is OPPONENT'S → destroy it. Per Plan 01 routing, it lands in the OPPONENT's discard (they own it).
   - Description: `"Your active Place: return it to your hand. Opponent's active Place: destroy it."`

2. **Huisbaas** (rework) — Replace the DEFERRED deck-search. Now reads from player's own discard:
   - Find the most recent `{ type: 'PLACE' }` entry in `player.discard`
   - Remove it from discard and push to `player.hand`
   - Works on any Place the player has previously lost (replaced OR destroyed)
   - Description: `"Return the most recently lost Place card from your discard pile to your hand."`
   - Remove the SUBSTANCE condition and old tags entirely.

3. **Chillingsvoorbij! (NEW snelle)** — Instant-speed version of Huisbaas. Same recovery logic but plays as a snelle (instant, any timing), letting you respond mid-opponent-turn.
   - Description: `"Instant: Return the most recently lost Place card from your discard pile to your hand."`
   - Flavour: `"De chill is over. Jij pakt 'm terug."`
   - Add to Physical Force snelle deck (replace snelle_lucky_coin).

**Helper pattern for Place recovery from player discard** (used by both Huisbaas and Chillingsvoorbij):
```js
// Find the most recent PLACE-type entry in player's discard
const placeIndex = state.players[playerId].discard.findIndex(
  c => (c.type === 'PLACE') || (c.cardId && String(c.cardId).startsWith('place_'))
);
if (placeIndex >= 0) {
  const [recovered] = state.players[playerId].discard.splice(placeIndex, 1);
  state.players[playerId].hand.push({ cardId: recovered.cardId ?? recovered, type: 'PLACE' });
}
```
Note: `findIndex` (not `[0]`) because the discard pile may contain piecie entries (strings or objects without type) interspersed — search for the FIRST PLACE specifically, not just the top card.

```js
export function effect_slecht_gezet(gameState) {
  if (!gameState.activePlace) {
    console.log('[ABILITY] Slecht Gezet: no active Place');
    return gameState;
  }
  const state = cloneState(gameState);
  const activePlayer = state.activePlayerId;
  const placeOwner = state.activePlacePlayedBy;

  if (placeOwner === activePlayer) {
    // YOUR own Place → return directly to hand (not via discard)
    const player = state.players[activePlayer];
    if (player) player.hand.push({ cardId: state.activePlace, type: 'PLACE' });
    state.activePlace = null;
    state.activePlacePlayedBy = null;
    state.activePlaceTurnsActive = 0;
    console.log('[ABILITY] Slecht Gezet: returned own Place to hand');
  } else {
    // Opponent's Place (or null owner) → destroy it
    // destroyActivePlace routes it to activePlacePlayedBy's discard (Plan 01 engine)
    const destroyed = state.activePlace;
    const ownerId = placeOwner || activePlayer;
    const owner = state.players[ownerId];
    if (owner) {
      if (!Array.isArray(owner.discard)) owner.discard = [];
      owner.discard.unshift({ cardId: destroyed, type: 'PLACE' });
    }
    state.activePlace = null;
    state.activePlacePlayedBy = null;
    state.activePlaceTurnsActive = 0;
    triggerPlaceDestroyedEffects(state, activePlayer);
    console.log('[ABILITY] Slecht Gezet: opponent Place destroyed');
  }
  return state;
}
```

```js
export function effect_huisbaas(gameState, playerId) {
  const state = cloneState(gameState);
  const player = state.players[playerId];
  if (!player) return state;
  const placeIndex = player.discard.findIndex(
    c => c?.type === 'PLACE' || (c?.cardId && String(c.cardId).startsWith('place_'))
  );
  if (placeIndex < 0) {
    console.log('[ABILITY] Huisbaas: no Place cards in discard');
    return state;
  }
  const [recovered] = player.discard.splice(placeIndex, 1);
  player.hand.push({ cardId: recovered.cardId ?? recovered, type: 'PLACE' });
  console.log('[ABILITY] Huisbaas: recovered', recovered.cardId ?? recovered, 'from discard to hand');
  return state;
}
```
