## Shared Pattern Extraction

**Pattern 1: Conditional MP Gain**
- Alyssa: base gain + conditional bonus based on event log
- Structure: gainMP (base) → ifThenElse(condition) → gainMP (bonus)

**Pattern 2: Per-Turn Limits**
- Jeffrey: `usageLimit: "once_per_turn"`
- DJ 80/20: Per-turn reroll limit (needs flag tracking)
- Already handled by executor, no special utility needed

**Pattern 3: Buff Application**
- Jeffrey: Applies `piecie_mp_restore_locked` buff to opponent
- Uses existing `applyBuff` primitive with expiryTurn

**Pattern 4: Roll Branching**
- Jisca: Roll 1d6, branch on [1-3] vs [4-6]
- Uses existing `rollBranch` primitive with range-based logic

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-001 | Tampering | Event Log Query (Alyssa) | mitigate | Filter events by type and targetSelf flag in checkEventLogThisTurn; validate minAmount >= 0 |

| T-01-003 | Denial of Service | Per-Turn Limits (Jeffrey, DJ) | mitigate | usageLimit and buff expiryTurn enforced by executor, not ability itself |
