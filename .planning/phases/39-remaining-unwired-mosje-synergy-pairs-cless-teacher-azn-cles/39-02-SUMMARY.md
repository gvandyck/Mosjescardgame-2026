## What Changed

- Wired the Gandoe/Michelle Physical Quest synergy in `src/abilities/questLogic.js`.
  - While `mosje_michelle` is on field, `mosje_gandoe_destroyer` gains +15 bonus MP on successful Physical Quests.
  - The partner synergy table now supports an optional `appliesTo` scope, so this row boosts Gandoe Destroyer only and does not accidentally boost Michelle.
- Wired the Michelle Tough Gamble kicker in `src/abilities/questLogic.js`.
  - While `mosje_gandoe_destroyer` is on field, Michelle Tough Gamble rolls 5-6 grant Gandoe Destroyer +10 MP.
  - The kicker uses `gainMP(..., { allowLevelUp: false })`, so it is MP-only and cannot trigger a level-up.
  - The existing Michelle Tough Gamble result bands stay unchanged: 4-6 doubles the quest reward, 1-3 halves it.
- Updated bot quest-risk prediction in `src/bot/strategy/assessQuestRisk.js` to pass the questing Mosje card id into partner-synergy prediction.
- Expanded permanent regression coverage in `tests/engine/gandoe-michelle-synergy.test.ts`.
  - Added a guard proving the +15 Physical Quest bonus is scoped to Gandoe, not Michelle.
  - Removed new explicit-`any` lint warnings from the Phase 39 test file.
- Updated `docs/card-reference.md` for Gandoe The Destroyer and Michelle Iron Tuk.
