<objective>
Fix BUG-03: Senor West wrong-guess penalty bypasses the MP floor clamp.

Currently `ability_martin_senor_west_calculated_guess()` does `player.activeSlots[si].mp -= 10` directly,
bypassing `loseMP()`. At MP=0 this produces -10 MP without triggering level regression or the floor clamp.

The fix has two parts:
1. Route the wrong-guess penalty through `loseMP()` (engine fix in mosjeAbilities.js)
2. Add an activation guard in main.js blocking ability use when Mosje is at level 0 AND mp 0

Purpose: Senor West must respect the same MP floor rules as every other card.
Output: mosjeAbilities.js with loseMP import + fixed penalty; west-calculated-guess.test.ts with floor/block tests; main.js with activation guard.
</objective>
