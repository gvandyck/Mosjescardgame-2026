<objective>
Fix BUG-04: Lucky Coin coin flip runs before checking Piecie slot availability.

Currently in main.js lines 1328-1348, `Math.random() < 0.5` flips the coin at line 1329.
The slot check only happens inside `playSnellie()` at line 1350+, after the flip.
With full slots: tails flips are consequence-free (player can cancel); heads grants no reroll
(playSnellie fails anyway) but the coin was still flipped.

Fix: add a slot-count check BEFORE line 1329 that shows a modal and returns early if slots full.

Purpose: The coin flip must be a committed action, not something the player can do risk-free.
Output: main.js with pre-flip guard; extended snelle-piecie-full-slots.test.ts.
</objective>
