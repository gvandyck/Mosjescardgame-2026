Fix BUG-02 and BUG-05 using shared infrastructure.

The fix introduces a `persistUntilEndOfTurn: true` property on the card definition.
`activatePiecie()` in turnManager.js must skip the discard step for flagged cards.

The fix adds `player.questPrepBonus += 2` to `ability_dj_8020_lucky_beats()`.
`questPrepBonus` is already read in main.js at quest resolution and reset to 0 when consumed —
this is the correct one-shot turn-modifier pattern. No new infrastructure needed.

Purpose: BUG-02 gives Dubbele Dosis a visible "stay in slot" lifecycle. BUG-05 wires DJ's
declared ability. Both share the questPrepBonus accumulation pattern.
