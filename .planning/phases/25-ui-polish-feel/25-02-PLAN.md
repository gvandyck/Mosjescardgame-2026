Inside `initLobbyPage()` in `src/main.js`, add the following after the deck select element is first referenced (after any existing deck-select population or listener code):

```javascript
// Deck tagline — show one-liner identity when player selects a deck
const deckTaglineEl = document.getElementById('deck-tagline');
function updateDeckTagline(deckId) {
  if (!deckTaglineEl) return;
  const deck = STARTER_DECKS.find(d => d.id === deckId);
  deckTaglineEl.textContent = deck?.tagline ?? '';
}
const deckSelectEl = document.getElementById('deck-select');
deckSelectEl?.addEventListener('change', (e) => updateDeckTagline(e.target.value));
updateDeckTagline(deckSelectEl?.value); // set tagline on initial page load
```

Rules:
- Do NOT add this outside of initLobbyPage — it must be scoped to the lobby page.
- STARTER_DECKS is already imported at line 18 — do not add another import.
- The `deck?.tagline ?? ''` guard handles custom decks (id not in STARTER_DECKS) by showing empty string rather than throwing.
- `updateDeckTagline` is a local function — not exported, not hoisted to module scope.
