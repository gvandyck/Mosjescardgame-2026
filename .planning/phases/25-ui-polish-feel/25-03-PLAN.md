**Step C — peakMP: add a trackPeakMP helper and call it after every render.**

Add this helper inside initGamePage (NOT exported):

```javascript
function trackPeakMP() {
  const localPlayer = gameState.players?.[localPlayerId];
  if (!localPlayer) return;
  (localPlayer.activeSlots || []).forEach(slot => {
    if (!slot) return;
    const mp = Number(slot.mp || 0);
    if (mp > gameStats.peakMP) gameStats.peakMP = mp;
  });
}
```

**Step D — mosjesLost: detect defeat transitions in renderAndCheckWin.**

Before each `renderFromState` call in `renderAndCheckWin`, capture a snapshot of the local player's active slot states. After render, compare:

```javascript
function renderAndCheckWin() {
  // Capture before-render slot states for mosjesLost detection
  const slotsBefore = (gameState.players?.[localPlayerId]?.activeSlots || [])
    .map(s => s ? { isDefeated: s.isDefeated, cardId: s.cardId } : null);

  renderFromState(gameState);

  // Detect newly defeated slots
  const slotsAfter = gameState.players?.[localPlayerId]?.activeSlots || [];
  slotsBefore.forEach((before, i) => {
    const after = slotsAfter[i];
    if (before && !before.isDefeated && after && after.isDefeated) {
      gameStats.mosjesLost += 1;
    }
  });

  trackPeakMP();
  if (isOffline && gameState.status === 'FINISHED') handleGameOver(gameState);
}
```

NOTE: `renderFromState` does not mutate gameState — it only renders to DOM. So gameState is the same object before and after the call. For mosjesLost, the right pattern is to diff the PREVIOUS gameState against the CURRENT gameState at each renderAndCheckWin invocation. If renderAndCheckWin is called with a new gameState already set, capture `slotsBefore` from the previous snapshot. To do this cleanly:

Add a `let prevActiveSlots = null;` variable at initGamePage scope alongside gameStats. Before each render, snapshot current activeSlots to prevActiveSlots, then compare after render:

```javascript
let prevActiveSlots = null; // initialized null; set after each render

function renderAndCheckWin() {
  const localSlots = gameState.players?.[localPlayerId]?.activeSlots || [];

  renderFromState(gameState);

  // Detect mosje defeats since last render
  if (prevActiveSlots) {
    prevActiveSlots.forEach((before, i) => {
      const after = localSlots[i];
      if (before && !before.isDefeated && after && after.isDefeated) {
        gameStats.mosjesLost += 1;
      }
    });
  }
  prevActiveSlots = localSlots.map(s => s ? { isDefeated: s.isDefeated } : null);

  trackPeakMP();
  if (isOffline && gameState.status === 'FINISHED') handleGameOver(gameState);
}
```
