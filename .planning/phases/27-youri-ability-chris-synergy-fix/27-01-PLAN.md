    - Returns { state, success: false, error: 'No face-down Piecies on field' } when piecieSlots has no face-down non-activated PIECIE slots
    - When exactly one face-down piecie: sets that slot's canActivateOnTurn = state.turnNumber, deducts 20 MP from Youri's activeSlot, draws 1 card from deck (if deck non-empty), increments youriAbilityUses, returns { state, success: true }
    - When multiple face-down piecies: deducts 20 MP from Youri's slot, increments youriAbilityUses, sets state.pendingYouriActivation = { playerId, faceDownSlots: [indices] } on state, does NOT draw card yet, returns { state, success: true, pendingYouriActivation: true }
    - Does NOT set instantPiecieThisTurn anywhere
  </behavior>
  <action>
Replace the entire `ability_youri_speed_activate` function in `src/abilities/mosjeAbilities.js` with the following logic:

1. Clone state with `cloneState(gameState)`.
2. Get `player = state.players[playerId]`. Return `{ state, success: false, error: 'Player not found' }` if missing.
3. Use-cap check: if `(player.youriAbilityUses || 0) >= 3` → return `{ state, success: false, error: 'Youri Speed Activate has already been used 3 times this game' }`.
4. Find Youri's active slot: `const youriSlot = player.activeSlots.find(s => s && !s.isDefeated && s.cardId === 'mosje_youri')`. If not found → return `{ state, success: false, error: 'Youri is not active on the field' }`.
5. MP check: if `youriSlot.mp < 20` → return `{ state, success: false, error: 'Not enough MP on Youri (need 20)' }`.
6. Find face-down piecies: `const faceDownIndices = player.piecieSlots.map((s, i) => (s && s.type === 'PIECIE' && s.faceDown && !s.activated) ? i : -1).filter(i => i >= 0)`. If length === 0 → return `{ state, success: false, error: 'No face-down Piecies on the field to activate' }`.
7. Deduct 20 MP from Youri's slot: `youriSlot.mp -= 20`. Increment counter: `player.youriAbilityUses = (player.youriAbilityUses || 0) + 1`.
8. If `faceDownIndices.length === 1`: set `player.piecieSlots[faceDownIndices[0]].canActivateOnTurn = state.turnNumber`. Draw 1 card: `if (player.deck.length > 0) { player.hand.push(player.deck.shift()); }`. Log: `console.log('[ABILITY] Youri: 20 MP paid, auto-activated piecie at slot ' + faceDownIndices[0] + ', drew 1 card')`. Return `{ state, success: true }`.
9. If multiple: set `state._pendingYouriActivation = { playerId, faceDownSlots: faceDownIndices }`. Log: `console.log('[ABILITY] Youri: 20 MP paid, awaiting piecie selection from ' + faceDownIndices.length + ' slots')`. Return `{ state, success: true, pendingYouriActivation: true }`.

Remove the old `player.instantPiecieThisTurn = true` line entirely. Update the comment above the function to match the correct description.

The `cloneState` helper is already imported at the top of `mosjeAbilities.js` — use it.
  </action>
