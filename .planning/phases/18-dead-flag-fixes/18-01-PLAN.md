Fix three dead-flag Piecies whose effect flags are set but never consumed, and mark them persistent so they stay visible on the field while their turn-long effect is pending.

1. **Those Eyelashes Tho** — `_snelleBlocked` is set but no code reads it. Wire it: store the *blocked opponent's playerId*, and have `playSnellie` reject Snelle plays from that player. (The +20 MP and opponent-discard already work.)

Wire it into `resolveQuest`: when the Battle Concert owner fails a quest **with Alyssa as the questing Mosje**, redirect the quest-failure MP loss to an opponent's first active Mosje instead of Alyssa, then clear the flag.

3. **Tweede Kans** — `_rerollGranted` is set but never read. Wire it into main.js quest dice-roll setup: when the flag is present, grant one extra reroll (fold into the existing `skiffaRerolls` count passed to `showDiceRoll`), then clear the flag.

**Flag hygiene:** `startTurn` must clear `_snelleBlocked`, `_battleConcertActive`, and `_rerollGranted` so a flag set but never triggered does not leak into later turns.
</objective>
