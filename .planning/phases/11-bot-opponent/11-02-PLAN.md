Inside the `initLobbyPage()` form submit handler (the `form.addEventListener('submit', async event => {...})` block), add the offline branch BEFORE the existing `if (mode === 'create')` block. The offline branch must run first so it short-circuits the Firebase path entirely.

The branch reads:
```js
const isOffline = document.getElementById('play-offline')?.checked === true;
if (isOffline) {
  // Pick a bot deck different from the human's pick
  const candidates = STARTER_DECKS.filter(d => d.id !== deckId);
  const botDeck = candidates.length > 0
    ? candidates[Math.floor(Math.random() * candidates.length)]
    : STARTER_DECKS[0];
  const botDeckId = botDeck.id;

  sessionStorage.setItem('mosjes:offline', JSON.stringify({
    name,
    deckId,
    botDeckId,
    playerId: 'player_1',
  }));

  window.location.href = `./game.html?offline=true&player=player_1`;
  return;
}
```

Place this block immediately after the `if (!name) { ... return; }` guard and before the `if (mode === 'join' && ...)` guard. This order is:
1. Validate name (existing)
2. **[NEW] If offline checkbox is checked → store session + navigate → return**
3. Validate room code for join mode (existing)
4. Persist custom deck def (existing)
5. Create/join room Firebase path (existing, unchanged)

Do NOT change anything inside `if (mode === 'create')` or `if (mode === 'join')`. The online path must be character-for-character identical to before.
