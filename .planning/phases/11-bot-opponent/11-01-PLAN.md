Create src/bot/botDriver.js as a single-export pure function module.

```js
// botDriver.js — Pure function. Runs the bot's full turn synchronously.
// Imports only from engine and data — never from multiplayer.
import { playPiecie, activatePiecie, playPlace, activatePlace,
         attemptGeneralQuest, attemptPersonalQuest, useMosjeAbility, endTurn } from '../engine/turnManager.js';
import { canAttemptGeneralQuest, canAttemptPersonalQuest } from '../abilities/questLogic.js';
import { PIECIES } from '../data/piecies.js';
import { PLACES } from '../data/places.js';
import { QUESTS } from '../data/quests.js';
import { MOSJES } from '../data/mosjes.js';
import { rollDie } from '../engine/deckEngine.js';

const PIECIE_LOOKUP = Object.fromEntries(PIECIES.map(c => [c.id, c]));
const PLACE_LOOKUP  = Object.fromEntries(PLACES.map(c => [c.id, c]));
const QUEST_LOOKUP  = Object.fromEntries(QUESTS.map(c => [c.id, c]));
```

Implement `export function driveBotTurn(gameState, botPlayerId)` following this exact priority order:

**Step 1 — Play Piecies from hand (all of them, not just one)**
Iterate player.hand. For each card where type === 'PIECIE':
  - Look up cardDef in PIECIE_LOOKUP
  - Call playPiecie(state, botPlayerId, cardRef, cardDef)
  - If result.success: update state = result.state; continue
  - If result.error includes 'slot' or 'full': break (no more room)
  - Otherwise: continue to next card

**Step 2 — Activate Piecies already on the field**
Iterate state.players[botPlayerId].piecieSlots (indices 0-3).
For each slot that is non-null, type === 'PIECIE', activated === false, and state.turnNumber >= slot.canActivateOnTurn:
  - Call activatePiecie(state, botPlayerId, slotIndex)
  - If result.success: update state = result.state

**Step 3 — Attempt General Quest**
Check: state.players[botPlayerId].questsAttemptedThisTurn < 1 (or < 2 if place_quest_haven is active).
Draw from sharedGeneralQuestDeck by calling attemptGeneralQuest(state).
If questCard is non-null:
  - Look up questDef in QUEST_LOOKUP
  - If questDef exists and canAttemptGeneralQuest(questDef, state, botPlayerId):
    - Import resolveQuest from questLogic.js.
    - Roll the die: import rollDie from '../engine/deckEngine.js'. Compute didSucceed = rollDie() >= 4.
    - Find the first active non-defeated Mosje slot index for botPlayerId.
    - Call resolveQuest(state, botPlayerId, questDef, didSucceed, firstActiveMosjeSlotIndex).
    - Update state = resolveQuest result.
    - Push questCard to state.sharedGeneralQuestDiscard.
  - Else: push questCard back to state.sharedGeneralQuestDiscard without resolving.
Update state.players[botPlayerId].questsAttemptedThisTurn = (existing + 1).

**Step 3b — Attempt Personal Quest**
After the General Quest step, scan state.players[botPlayerId].hand for any card where type === 'QUEST' and questType === 'PERSONAL' (look up questType via QUEST_LOOKUP using card.cardId).
For the first such card found:
  - Look up questDef in QUEST_LOOKUP
  - If questDef exists and canAttemptPersonalQuest(questDef, state, botPlayerId) returns true:
    - Call attemptPersonalQuest(state, botPlayerId, card.cardId)
    - If result.success: update state = result.state

**Step 4 — Play Places from hand**
Iterate player.hand. For each card where type === 'PLACE':
  - Look up cardDef in PLACE_LOOKUP
  - Call playPlace(state, botPlayerId, cardRef, cardDef)
  - If result.success: update state = result.state; break (one Place per turn is enough)

**Step 5 — Activate Places already on the field (face-down)**
Iterate state.players[botPlayerId].piecieSlots.
For each slot where type === 'PLACE', activated === false, state.turnNumber >= slot.canActivateOnTurn:
  - Call activatePlace(state, botPlayerId, slotIndex)
  - If result.success: update state = result.state; break

**Step 6 — Use Mosje ability**
Find the first active non-defeated Mosje in state.players[botPlayerId].activeSlots where abilityUsedThisTurn === false.
If found, look up MOSJES to confirm mosjeDef.abilityId exists.
Call useMosjeAbility(state, botPlayerId, mosje.cardId).
If result.success: state = result.state.

**Step 7 — endTurn**
state = endTurn(state).

Return state.

Important: NEVER import from src/multiplayer/. NEVER call pushState or listenToState.
The function must not mutate the input — all turnManager functions already do deep clones, so as long as you only reassign `state` (never mutate `gameState` directly), this is guaranteed.
