## Reusable Code Patterns

### Pattern 1: Simple MP Gain
```typescript
effects: [{ primitive: "gainMP", params: { target: "$self", amount: 25 } }]
```
**Used by:** kannetje-melk (25), nature-s-gift (30)

### Pattern 2: Conditional MP Gain (with opponent drain)
```typescript
effects: [
  { primitive: "loseMP", params: { target: "$opponent", amount: 15 } },
  { primitive: "gainMP", params: { target: "$self", amount: 10 } }
]
```
**Used by:** snoeiertje

### Pattern 3: MP Drain (enemy → self)
```typescript
effects: [
  { primitive: "loseMP", params: { target: "$opponent", amount: 20 } },
  { primitive: "gainMP", params: { target: "$self", amount: 20 } }
]
```
**Used by:** momentum-diefje

### Pattern 4: Multi-effect (loss + draw)
```typescript
effects: [
  { primitive: "loseMP", params: { target: "$opponent", amount: 35 } },
  { primitive: "gainMP", params: { target: "$self", amount: 0 } },
  { primitive: "drawCards", params: { target: "$self", count: 2 } }
]
```
**Used by:** dikke-taks

### Pattern 5: Substance cards (gain MP but lose MP)
```typescript
effects: [
  { primitive: "gainMP", params: { target: "$self", amount: 30 } },
  { primitive: "loseMP", params: { target: "$self", amount: 15 } }
]
```
**Used by:** grammetje-pieter

### Pattern 6: Pet synergy (damage reduction buff)
```typescript
effects: [
  { primitive: "applyBuff", params: { 
    target: "$self", 
    buffType: "damageReduction", 
    percent: 50, 
    duration: 2 
  } }
]
```
**Used by:** bowie-stormey (conditional 75% if pet synergy)

### Pattern 7: Utility (draw cards)
```typescript
effects: [{ primitive: "drawCards", params: { target: "$self", count: 2 } }]
```
**Used by:** gun-een-piece

### Pattern 8: Next-turn MP gain (deferred)
```typescript
effects: [{ primitive: "gainMP", params: { target: "$self", amount: 40, timing: "nextTurn" } }]
```
**Used by:** tikker

## Implementation Order

1. **Momentum-Gaining** — most cards, simplest logic
2. **Attack** — medium complexity, existing patterns
3. **Utility** — includes complex effects, varied logic
4. **Substance** — few cards, straightforward patterns
5. **Pet** — synergy mechanics, conditional buffs
6. **Shared/References** — cross-deck cards

**Rationale:** Start with high-count, simple-effect categories to build velocity and establish patterns. Move to higher-complexity (utility, pets) once rhythm is established.
