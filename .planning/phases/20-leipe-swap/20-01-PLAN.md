<objective>
Rework the unused **Emergency Swap** Piecie into **Leipe Swap** (*leip* = Dutch slang for sick/crazy — a wild MP swap). Signature card: **max rarity ★★★★★ (=> 1 per deck), no MP cost, stays on the field for the turn.**

Mechanic — a temporary MP **double-swap** (design locked with the user):
1. **On activation (your turn):** pick one of YOUR Mosjes + an OPPONENT Mosje; swap their MP (levels untouched).
2. **Your turn plays out:** your Mosje can gain MP and auto-level at 100 (the level sticks). The opponent Mosje is idle.
3. **End of your turn:** swap the two slots' **current** MP back, then the card sweeps off the field.

Because the opponent Mosje sits holding your original MP untouched, the end-of-turn swap-back returns your original MP to you, your banked level(s) stay, and the opponent is left holding your leftover. Worked example (locked):

| | You (Coert) | Opp (Binti) |
|---|---|---|
| start | L1·30 | L2·80 |
| swap | L1·80 | L2·30 |
| you quest +40 → 120 → auto-level | **L2·20** | L2·30 |
| end-of-turn swap current back (20↔30) | **L2·30** | L2·**20** |

Net: you banked a level, MP back to 30; opponent drained 80→20. (If you DON'T level, your turn's gains get handed to the opponent — accepted skill check.)

This is the imperative-engine path (effect + endTurn + target modals), consistent with Phases 18-19. The swap uses **direct mp assignment, never gainMP/loseMP** (those auto-level at 100 and would break a progress swap).
</objective>

```js
// Leipe Swap — temporary MP swap. The UI (main.js) picks one of the player's
// Mosjes + an opponent Mosje and passes their slot refs via _pendingTargets.
// Swap their MP now (direct assignment, NOT gainMP/loseMP — we must not auto-level
// off the swapped progress). Record the pair so endTurn can swap the CURRENT mp back.
export function effect_leipe_swap(gameState, playerId) {
  const state = cloneState(gameState);
  const t = state._pendingTargets || {};
  const yourSlotIndex = t.leipeYourSlot;
  const oppId = t.leipeOppId;
  const oppSlotIndex = t.leipeOppSlot;
  const me = state.players[playerId];
  const opp = oppId ? state.players[oppId] : null;
  // Graceful no-op without targets (bot/sim path never sets _pendingTargets here)
  if (!me || !opp || yourSlotIndex == null || oppSlotIndex == null) return state;
  const yourSlot = me.activeSlots?.[yourSlotIndex];
  const oppSlot = opp.activeSlots?.[oppSlotIndex];
  if (!yourSlot || !oppSlot || yourSlot.isDefeated || oppSlot.isDefeated) return state;
  const tmp = yourSlot.mp;
  yourSlot.mp = oppSlot.mp;
  oppSlot.mp = tmp;
  state._leipeSwap = { byPlayerId: playerId, yourSlotIndex, oppId, oppSlotIndex };
  if (state._pendingTargets) {
    delete state._pendingTargets.leipeYourSlot;
    delete state._pendingTargets.leipeOppId;
    delete state._pendingTargets.leipeOppSlot;
  }
  console.log('[PIECIE] Leipe Swap: swapped MP', `${playerId}#${yourSlotIndex}`, '<->', `${oppId}#${oppSlotIndex}`);
  return state;
}
```
